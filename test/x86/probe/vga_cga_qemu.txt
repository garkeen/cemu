#       -device isa-debug-exit,iobase=0xf4,iosize=0x4
#
# Mode 6 as SeaBIOS's stdvgamodes shapes it: SR2=01 (plane 0 only), SR4=06
# (odd/even on, no chain 4), GR6=0x0D (the aperture at 0xB8000), AR10=01
# (graphics) and AR12=01 (colour plane 0). The probe fills 4KB one byte at a
# time with 0x11,0x12,... then reads back:
#   same=  32 bytes at the write addresses
#   odd=   32 bytes at the other parity (does the parity bit alias?)
#   word=  32 bytes after a word-at-a-time fill of the same window
# Exit: debug-exit 5 -> status 11 on both.

The values are the card's answers, not a self-judgement: a model that ignores
odd/even aliasing or that splits word writes differently prints a different
line. This pins the mode 6 aperture; the display address generator that turns
those bytes into scan lines is not guest-readable and is checked by
fbdump/screendump instead (progress.md D33).
